# Resume Roaster

Resume Roaster is an AI-powered resume analysis tool that evaluates your CV or resume and provides detailed feedback. Upload your resume and get instant insights on its strengths, weaknesses, ATS compatibility, and areas for improvement.

## What It Does

- **Resume Analysis** — Analyzes your resume content, design, and language
- **ATS Compatibility Check** — Determines if your resume is ATS-friendly
- **Strengths & Positives** — Highlights what's working well in your resume
- **Weaknesses & Negatives** — Identifies areas that need improvement
- **Missing Elements** — Points out important sections or keywords you might be missing
- **Detailed Feedback** — Provides actionable suggestions to enhance your resume

## Features

- Upload and analyze resumes instantly
- AI-powered resume roasting and feedback
- ATS friendliness scoring
- Detailed breakdown of positive and negative aspects
- Smart recommendations for improvement
- User-friendly interface

## Technologies Used

- **React** & **TypeScript** — Modern, type-safe frontend interface
- **Django** — Robust backend API
- **Groq Llama Model** — Advanced AI for resume analysis and intelligent feedback
- **CSS** — Responsive and clean UI design

## Getting Started

1. Clone the repository.
2. Install frontend dependencies: `npm install` (in the frontend directory)
3. Install backend dependencies: `pip install -r requirements.txt` (in the backend directory)
4. Configure your Groq API key in the environment variables
5. Start the Django backend server
6. Start the React frontend development server
7. Open your browser and upload your resume to get started

## Usage

1. Visit the application
2. Upload your resume (PDF or DOC format)
3. Click "Roast My Resume" to analyze
4. Get detailed feedback on your resume quality
5. Review suggestions and improve your resume
